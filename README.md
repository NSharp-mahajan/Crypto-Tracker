# 💸 CryptoScope – Real-Time Crypto Price Tracker & Landing Page

CryptoScope is a sleek, React-powered application to track real-time cryptocurrency prices using the CoinGecko API. Designed with Gen-Z UX in mind, it includes a stunning landing page, light/dark theme toggle, and plans for powerful features like favorites, sorting, and coin detail views.

---

## 🔥 Features

- 🚀 Landing page with clean, modern UI
- 🌗 Dark/Light Mode toggle
- 📈 Real-time crypto prices from CoinGecko API
- ⚛️ Built with React.js + Vite
- 📱 Fully responsive design

---

## 🛠️ Tech Stack

- React.js
- Vite
- CoinGecko API
- CSS (custom + responsive)
- LocalStorage (for upcoming features like Favorites)

---

## 📌 Upcoming Features

- 🔍 Search + Sorting filters
- ❤️ Add coins to Favorites
